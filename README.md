# Los-Angeles-Crime-Analysis
This project performs an EDA on Los Angeles crime data (2020–2023) using Python. I cleaned over 185k LAPD records, engineered temporal features, and visualized hourly spikes to identify public safety patterns. The analysis focuses on victim demographics and geographic hotspots to support data-driven resource allocation.
Tech Stack:
Language: Python  
Libraries: Pandas (Data Cleaning), Matplotlib & Seaborn (Visualization)  
Dataset: LAPD Crime Data (2020-2023)
